# Stamp Book — วันวิทย์68

เว็บสะสมตราประทับประจำฐาน เด็กสแกน QR code ที่ติดไว้ตามฐาน ถ้า id ตรงก็ได้ตราประทับ
เก็บให้ครบทั้ง 7 ฐาน

เป็น **static site ล้วน ไม่มี build step** — ไม่ต้อง `npm install` ไม่ต้องรัน server อะไรทั้งสิ้น

---

## 1. Deploy ขึ้น GitHub Pages

**สำคัญสุด: ตอนใช้จริงต้องเป็น `https://`** เบราว์เซอร์ไม่ยอมให้เปิดกล้องบน `http://`
(ยกเว้น `localhost`) — GitHub Pages ให้ HTTPS มาอยู่แล้ว ไม่ต้องตั้งอะไรเพิ่ม

โฟลเดอร์นี้เตรียมพร้อม push แล้ว มี `.nojekyll` (กัน Jekyll ของ Pages กินไฟล์),
มี `.gitignore` (กัน cert ของเครื่องตัวเองหลุดขึ้น repo) และ path ทุกอันเป็น **relative**
เลยรันได้ทั้งที่ `user.github.io/` และใน subpath `user.github.io/repo/` — เทสมาแล้วทั้งสองแบบ

```bash
git init -b main
git add .
git commit -m "Wunvit stamp book"
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

(รันในโฟลเดอร์ `Wunvit stampbook` นี้)

จากนั้นในหน้า repo: **Settings → Pages → Source: Deploy from a branch →
Branch: `main` / `/ (root)` → Save** รอสัก 1–2 นาทีแล้วเข้า
`https://<username>.github.io/<repo>/`

> ตั้งชื่อ repo เป็นตัวเล็กไม่มีเว้นวรรค เช่น `wunvit-stampbook` — ไม่งั้น URL จะมี `%20`
> โผล่มาน่าเกลียด คำสั่งข้างบน push **ข้างในโฟลเดอร์นี้** เป็น root ของ repo อยู่แล้ว
> ชื่อโฟลเดอร์บนเครื่องที่มีเว้นวรรคจึงไม่ไปโผล่ใน URL

### โฮสต์อื่น ถ้าอยากได้ไวกว่านั้น

| วิธี | ขั้นตอน |
| --- | --- |
| **Netlify Drop** | เปิด [app.netlify.com/drop](https://app.netlify.com/drop) ลากโฟลเดอร์นี้ลงไป ได้ URL ทันที ไม่ต้องใช้ git |
| **Cloudflare Pages** | Create project → Direct Upload → ลากโฟลเดอร์ |
| **Vercel** | `vercel` ในโฟลเดอร์นี้ (framework: Other, ไม่ต้องใส่ build command) |

ทุกเจ้าไม่ต้องตั้ง build command / output directory อะไรเลย root คือ `index.html`

### ไฟล์ที่เว็บใช้จริง

```
index.html
assets/          (css, js, fonts, img — จำเป็นทั้งหมด)
.nojekyll        (เฉพาะ GitHub Pages)
```

`qr code/`, `image/`, `serve.py`, `context.md`, `README.md` เว็บไม่ได้เรียกใช้
แต่ push ขึ้นไปด้วยก็ดี QR ต้นฉบับจะได้ไม่หาย — รวมทั้ง repo ยังไม่ถึง 5 MB
ส่วนที่เบราว์เซอร์ต้องโหลดจริงๆ ประมาณ **676 KB**

## 2. ทดสอบบนเครื่องตัวเอง

```bash
python serve.py
```

เปิด `http://localhost:8000/` — **กล้องใช้ได้เลย ไม่มี certificate warning**
เพราะ `localhost` นับเป็น secure context อยู่แล้ว ไม่ต้องพึ่ง https

ถ้าจะเทสจาก **มือถือ** ในวง wifi เดียวกัน อันนี้ต้องใช้ https เพราะเลข IP วงแลนไม่นับ:

```bash
python serve.py --lan
```

สคริปต์จะพิมพ์ URL แบบ `https://192.168.x.x:8443/` ให้ cert เป็น self-signed
มือถือจะเตือนครั้งเดียว กด **Advanced → Proceed anyway** แล้วกล้องใช้งานได้ปกติ
คำเตือนนี้เกิดเฉพาะตอนเทสในบ้าน — ขึ้น Pages จริงแล้วไม่มี

## 3. ความคืบหน้าเก็บยังไง (เน็ตหลุดแล้วไม่หาย)

เก็บใน **`localStorage` ของเครื่องนั้นๆ** ไม่ได้เก็บบน server เลย

- สแกนติดปุ๊บ เขียนลงเครื่องทันที ไม่ต้องรอ network
- เน็ตหลุด / ปิดแอป / ปิดจอ / เปิดใหม่ → ความคืบหน้ายังอยู่ครบ
- ไม่มี login ไม่มีบัญชี **1 เครื่อง = 1 สมุด** ถ้าเด็กเปลี่ยนเครื่องหรือล้าง browser data จะเริ่มใหม่
- ถ้าเปิดใน incognito ที่เขียน `localStorage` ไม่ได้ แอปจะเก็บไว้ในหน่วยความจำแทน
  (ยังเล่นจนจบได้ แต่ปิดแท็บแล้วหาย) — ไม่ค้างไม่พัง

key ที่ใช้คือ `wunvit_stampbook_v1` หน้าตาแบบนี้:

```json
{ "v": 1, "stamps": { "health_qrcode": "2026-08-19T12:00:00.000Z" } }
```

ปุ่ม **ล้างความคืบหน้า** อยู่ในหน้า My Progress (มี confirm ก่อน) ไว้ให้พี่สตาฟกดล้าง
ก่อนส่งเครื่องต่อให้เด็กคนถัดไป

## 4. ฐานทั้ง 7 กับ QR code

| QR code (ข้อความในโค้ด) | ชื่อฐาน |
| --- | --- |
| `food_qrcode` | ฐานอาหาร |
| `health_qrcode` | ฐานสุขภาพการแพทย์ |
| `energy_qrcode` | ฐานพลังงานและวัสดุ |
| `environment_qrcode` | ฐานสิ่งแวดล้อม |
| `agriculture_qrcode` | ฐานการเกษตร |
| `space_qrcode` | ฐานเทคโนโลยีอวกาศ |
| `travel_qrcode` | ฐานการเดินทางและขนส่ง ⚠️ |

⚠️ พี่ให้ชื่อฐานไทยมา 6 ชื่อ แต่ QR มี 7 อัน — `travel_qrcode` เลยยังไม่มีชื่อที่พี่กำหนด
ผมตั้งไว้ให้ก่อนว่า **ฐานการเดินทางและขนส่ง** ถ้าจะเปลี่ยนแก้บรรทัดเดียวที่ `BASES`
ใน [assets/js/app.js](assets/js/app.js) พอ ไม่ต้องไปแตะที่อื่น

**หนึ่ง QR = หนึ่งฐานเท่านั้น** ใช้ข้ามฐานไม่ได้ สแกนซ้ำก็ไม่นับเพิ่ม (ขึ้นว่า "สแกนไปแล้ว")
ส่วน QR ที่ไม่ใช่ของงาน (เช่น QR ร้านค้า) จะโดนปฏิเสธและบอกให้สแกนใหม่
เทสมาแล้วครบทั้ง 7 อัน ยิงวิดีโอ QR ตัวจริงเข้ากล้อง ไม่มีอันไหนข้ามฐาน

QR code ตัวจริงสำหรับเอาไปปรินต์อยู่ใน `qr code/`

### ถ้าจะเพิ่ม / แก้ฐาน

แก้ array `BASES` ที่หัวไฟล์ [assets/js/app.js](assets/js/app.js) อย่างเดียว
จำนวนฐานทั้งหมด ตัวนับ วงกลม progress และรายการฐาน คำนวณจาก array นี้หมด
ไม่ต้องแก้ HTML/CSS

```js
{ id: 'food_qrcode', name: 'ฐานอาหาร', icon: '🍜' },
```

## 5. เรื่องกล้อง

- ใช้ `BarcodeDetector` ของเบราว์เซอร์ถ้ามี (Android Chrome — เร็วและทนแสงน้อยกว่า)
  ถ้าไม่มีก็ใช้ jsQR ที่ฝังมาในโฟลเดอร์ (iOS Safari, Firefox)
- **ซูม** ถ้ากล้องรองรับซูมจริง (มือถือส่วนใหญ่รองรับ) สไลเดอร์จะไปคุมเลนส์โดยตรง
  ถ้าไม่รองรับจะ crop ภาพให้แทน ช่วยเรื่องเล็งเป็นหลัก
- ถ้าเคยกดอนุญาตกล้องไปแล้ว รอบต่อไปเข้าหน้าสแกนกล้องจะเปิดเองเลย ไม่ต้องกดซ้ำ
- ออกจากหน้าสแกนหรือสลับไปแอปอื่น กล้องจะปิดให้อัตโนมัติ (ไม่กินแบต ไม่ร้อน)
- มีไฟฉายให้กดถ้าเครื่องรองรับ เผื่อฐานอยู่ในที่มืด

### ปรินต์ QR ให้ใหญ่พอ

จากที่ทดสอบ ตัวสแกนอ่านได้เมื่อ QR กินพื้นที่ **ประมาณ 8% ของความกว้างภาพขึ้นไป**
แปลว่าถ้าปรินต์ QR ขนาด A5 (~15 ซม.) เด็กยืนห่างได้สบายๆ ถ้าปรินต์เล็กกว่า A6
ควรบอกให้เด็กเข้าไปใกล้ๆ หรือใช้ซูมช่วย

## 6. โครงสร้างไฟล์

```
index.html              ทั้งแอปอยู่ในไฟล์เดียว 3 หน้า (landing / scan / progress)
assets/css/app.css      design system + ทุกหน้า
assets/css/fonts.css    @font-face ชี้ไปที่ฟอนต์ในเครื่อง
assets/js/app.js        ฐานข้อมูลฐาน, storage, router, scanner  ← แก้ฐานที่นี่
assets/js/jsqr.js       jsQR 1.4.0 (vendored)
assets/fonts/           Osiris (หัวเรื่องอังกฤษ), IBM Plex Sans Thai, IBM Plex Mono
assets/img/             ภาพพื้นหลัง + ภาพการ์ด 2 ใบ (.webp)
.nojekyll               บอก GitHub Pages ว่าอย่าเอา Jekyll มายุ่ง
context.md              บันทึกการตัดสินใจ/สเปกของงานนี้
serve.py                เซิร์ฟเวอร์ไว้เทสในเครื่อง (ไม่เกี่ยวกับตอน deploy)
image/, qr code/        ไฟล์ต้นฉบับที่พี่ให้มา
```

ฟอนต์ทั้งหมดฝังมาในโฟลเดอร์ ไม่ได้ดึงจาก Google Fonts ตอนรัน — หน้าเว็บเลยไม่วูบ
ถ้า wifi งานช้า และไม่มี request ออกนอกเครื่องเลยสักอัน

ภาพในเว็บแปลงเป็น `.webp` แล้ว (4.1 MB → 129 KB) เพื่อให้เด็กที่เล่นผ่านเน็ตมือถือ
โหลดครั้งแรกไว ไฟล์ PNG ต้นฉบับที่พี่ให้มายังอยู่ครบใน `image/` ไม่ได้แตะ
