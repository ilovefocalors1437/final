# PASSPORT — วันวิทย์69

เว็บสะสมแสตมป์ประจำฐาน นักเรียนสแกน QR ที่ติดไว้ตามฐาน ถ้า id ตรงก็ได้แสตมป์
สะสมครบตามเกณฑ์ทั้งสองกลุ่มแล้วเอาไปแลกรางวัลที่กองกลาง

เป็น **static site ล้วน ไม่มี build step** — ไม่ต้อง `npm install` ไม่ต้องรัน server อะไรทั้งสิ้น

## 0. ถ้าเว็บขึ้นแต่หน้าตาเป็นตัวหนังสือเปล่าๆ

แปลว่า `index.html` ขึ้นไปแล้ว แต่โฟลเดอร์ `assets/` ไม่ได้ตามไปด้วย (อัปผ่านหน้าเว็บ
GitHub มันชอบไม่เอาโฟลเดอร์ไป) เช็คได้ที่หน้า repo ว่ามีโฟลเดอร์ `assets` ไหม

**ทางที่พังไม่ได้: ใช้ไฟล์เดียวจบ**

```bash
python build_standalone.py
```

ได้ `standalone/index.html` ไฟล์เดียว ~1.5 MB ที่ยัด CSS, JS, ฟอนต์, รูป ไว้ข้างในหมด
**ไม่มีการโหลดไฟล์อื่นเลยแม้แต่ไฟล์เดียว** — เอาไฟล์นี้ไฟล์เดียวไปวางแทน `index.html`
ใน repo ก็จบ ไม่ต้องมี `assets/` ไม่ต้องห่วงว่าอะไรจะหาย

แก้อะไรใน `assets/` แล้วรัน 2 คำสั่งนี้ก่อน commit:

```bash
python stamp_assets.py
python build_standalone.py
```

`stamp_assets.py` สำคัญมาก — มันใส่ `?v=<hash>` ต่อท้าย css/js ทำให้เครื่องที่เคย
เปิดเว็บไปแล้วโหลดของใหม่จริงๆ ถ้าไม่รัน เด็กที่เคยเข้าเว็บจะยังเห็นเวอร์ชันเก่าค้าง
(เจอมาแล้วตอน deploy จริง)

## 1. Deploy ขึ้น GitHub Pages

**สำคัญสุด: ตอนใช้จริงต้องเป็น `https://`** เบราว์เซอร์ไม่ยอมให้เปิดกล้องบน `http://`
(ยกเว้น `localhost`) — GitHub Pages ให้ HTTPS มาอยู่แล้ว ไม่ต้องตั้งอะไรเพิ่ม

โฟลเดอร์นี้เตรียมพร้อม push แล้ว มี `.nojekyll` (กัน Jekyll ของ Pages กินไฟล์),
มี `.gitignore` (กัน cert ของเครื่องตัวเองหลุดขึ้น repo) และ path ทุกอันเป็น **relative**
เลยรันได้ทั้งที่ `user.github.io/` และใน subpath `user.github.io/repo/` — เทสมาแล้วทั้งสองแบบ

```bash
git init -b main
git add .
git commit -m "Wunvit passport"
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

(รันในโฟลเดอร์ `Wunvit stampbook` นี้)

จากนั้นในหน้า repo: **Settings → Pages → Source: Deploy from a branch →
Branch: `main` / `/ (root)` → Save** รอสัก 1–2 นาทีแล้วเข้า
`https://<username>.github.io/<repo>/`

> ตั้งชื่อ repo เป็นตัวเล็กไม่มีเว้นวรรค เช่น `wunvit-stampbook` — ไม่งั้น URL จะมี `%20`
> โผล่มาน่าเกลียด คำสั่งข้างบน push **ข้างในโฟลเดอร์นี้** เป็น root ของ repo อยู่แล้ว
> ชื่อโฟลเดอร์บนเครื่องที่มีเว้นวรรคจึงไม่ไปโผล่ใน URL

### โฮสต์อื่น ถ้าอยากได้ไวกว่านั้น

| วิธี | ขั้นตอน |
| --- | --- |
| **Netlify Drop** | เปิด [app.netlify.com/drop](https://app.netlify.com/drop) ลากโฟลเดอร์นี้ลงไป ได้ URL ทันที ไม่ต้องใช้ git |
| **Cloudflare Pages** | Create project → Direct Upload → ลากโฟลเดอร์ |
| **Vercel** | `vercel` ในโฟลเดอร์นี้ (framework: Other, ไม่ต้องใส่ build command) |

ทุกเจ้าไม่ต้องตั้ง build command / output directory อะไรเลย root คือ `index.html`

### ไฟล์ที่เว็บใช้จริง

```
index.html
assets/          (css, js, fonts, img — จำเป็นทั้งหมด)
.nojekyll        (เฉพาะ GitHub Pages)
```

> ถ้าอัปผ่านหน้าเว็บ GitHub (Add file → Upload files) ให้**ลากทั้งโฟลเดอร์**
> ไม่ใช่ลากทีละไฟล์ ไม่งั้น `assets/` จะไม่ขึ้นไปแล้วหน้าเว็บจะโล้นแบบไม่มี CSS
> — หรือใช้วิธีไฟล์เดียวในหัวข้อ 0 ไปเลยจะชัวร์กว่า

`qr code/`, `image/`, `serve.py`, `context.md`, `README.md` เว็บไม่ได้เรียกใช้
แต่ push ขึ้นไปด้วยก็ดี QR ต้นฉบับจะได้ไม่หาย — รวมทั้ง repo ยังไม่ถึง 5 MB
ส่วนที่เบราว์เซอร์ต้องโหลดจริงๆ ประมาณ **1.1 MB** (โปสเตอร์โหลดเฉพาะตอนเปิดหน้ากิจกรรม)

## 2. ทดสอบบนเครื่องตัวเอง

```bash
python serve.py
```

เปิด `http://localhost:8000/` — **กล้องใช้ได้เลย ไม่มี certificate warning**
เพราะ `localhost` นับเป็น secure context อยู่แล้ว ไม่ต้องพึ่ง https

ถ้าจะเทสจาก **มือถือ** ในวง wifi เดียวกัน อันนี้ต้องใช้ https เพราะเลข IP วงแลนไม่นับ:

```bash
python serve.py --lan
```

สคริปต์จะพิมพ์ URL แบบ `https://192.168.x.x:8443/` ให้ cert เป็น self-signed
มือถือจะเตือนครั้งเดียว กด **Advanced → Proceed anyway** แล้วกล้องใช้งานได้ปกติ
คำเตือนนี้เกิดเฉพาะตอนเทสในบ้าน — ขึ้น Pages จริงแล้วไม่มี

## 3. ความคืบหน้าเก็บยังไง (เน็ตหลุดแล้วไม่หาย)

เก็บใน **`localStorage` ของเครื่องนั้นๆ** ไม่ได้เก็บบน server เลย

- สแกนติดปุ๊บ เขียนลงเครื่องทันที ไม่ต้องรอ network
- เน็ตหลุด / ปิดแอป / ปิดจอ / เปิดใหม่ → ความคืบหน้ายังอยู่ครบ
- ไม่มี login ไม่มีบัญชี **1 เครื่อง = 1 สมุด** ถ้าเด็กเปลี่ยนเครื่องหรือล้าง browser data จะเริ่มใหม่
- ถ้าเปิดใน incognito ที่เขียน `localStorage` ไม่ได้ แอปจะเก็บไว้ในหน่วยความจำแทน
  (ยังเล่นจนจบได้ แต่ปิดแท็บแล้วหาย) — ไม่ค้างไม่พัง

key ที่ใช้คือ `wunvit_stampbook_v1` หน้าตาแบบนี้:

```json
{ "v": 2, "stamps": { "gh_qrcode": "2026-08-19T12:00:00.000Z" } }
```

**ไม่มีปุ่มล้างความคืบหน้าในแอป** (เอาออกตามที่สั่ง) ถ้าจะส่งเครื่องต่อให้นักเรียน
คนถัดไปแล้วต้องเริ่มใหม่ ให้ล้าง site data ของเว็บนี้ในเบราว์เซอร์ หรือเปิดในหน้าต่าง
ส่วนตัว (incognito) แยกคนละคน

## 4. ฐานทั้งหมด กับ QR code

มี 2 กลุ่ม เกณฑ์แยกกัน **ต้องผ่านทั้งสองกลุ่ม** ถึงจะรับรางวัลได้

| กลุ่ม | จำนวนฐาน | ต้องได้อย่างน้อย |
| --- | --- | --- |
| ฐานกิจกรรมวิชาเอก | 11 | **5 แสตมป์** |
| ฐานนวัตกรรมและนิทรรศการแสดงผลงาน | 8 | **3 แสตมป์** |

### ฐานกิจกรรมวิชาเอก (11 ฐาน)

| QR (ข้อความในโค้ด) | ชื่อฐาน |
| --- | --- |
| `gh_qrcode` | ฐานกิจกรรมวิชาเอก GH |
| `gi_qrcode` | ฐานกิจกรรมวิชาเอก GI |
| `sg_qrcode` | ฐานกิจกรรมวิชาเอก SG |
| `sa_qrcode` | ฐานกิจกรรมวิชาเอก SA |
| `ht_qrcode` | ฐานกิจกรรมวิชาเอก HT |
| `hs_qrcode` | ฐานกิจกรรมวิชาเอก HS |
| `hp_qrcode` | ฐานกิจกรรมวิชาเอก HP |
| `ha_qrcode` | ฐานกิจกรรมวิชาเอก HA |
| `da_qrcode` | ฐานกิจกรรมวิชาเอก DA |
| `hdci_qrcode` | ฐานกิจกรรมวิชาเอก HDCI ⚠️ |
| `spb_qrcode` | ฐานกิจกรรมวิชาเอก SPB |

⚠️ ในรูป passport ตัวนี้พิมพ์แยกสองบรรทัด "HD / CI" ผมอ่านเป็นฐานเดียวชื่อ **HDCI**
ถ้าจริงๆ เป็นสองฐานแยกกัน บอกได้เลย เพิ่มอีกแถวใน `BASES` แล้วรัน `make_qr_codes.py` ใหม่รอบเดียวจบ

### ฐานนวัตกรรมและนิทรรศการแสดงผลงาน (8 ฐาน)

| QR (ข้อความในโค้ด) | ชื่อฐาน |
| --- | --- |
| `space_qrcode` | ฐานนวัตกรรมด้านเทคโนโลยีและอวกาศ |
| `environment_qrcode` | ฐานนวัตกรรมด้านสิ่งแวดล้อม |
| `agriculture_qrcode` | ฐานนวัตกรรมด้านการเกษตร |
| `energy_qrcode` | ฐานนวัตกรรมด้านพลังงานและวัสดุ |
| `health_qrcode` | ฐานนวัตกรรมด้านสุขภาพและการแพทย์ |
| `travel_qrcode` | ฐานการท่องเที่ยว |
| `food_qrcode` | ฐานนวัตกรรมด้านอาหาร |
| `exhibition_qrcode` | นิทรรศการแสดงผลงาน ⭐ |

⭐ อันนี้ผม**เพิ่มให้**ครับ — ใน passport มี "นิทรรศการแสดงผลงาน" อยู่ในกลุ่มนี้ (นับรวมใน 3 แสตมป์)
แต่ยังไม่มี QR ผมสร้างให้แล้ว

**หนึ่ง QR = หนึ่งฐานเท่านั้น** ใช้ข้ามฐานหรือข้ามกลุ่มไม่ได้ สแกนซ้ำก็ไม่นับเพิ่ม (ขึ้นว่า "สแกนไปแล้ว")
ส่วน QR ที่ไม่ใช่ของงาน (เช่น QR ร้านค้า) จะโดนปฏิเสธและบอกให้สแกนใหม่
เทสมาแล้วครบทั้ง 19 อัน ยิงวิดีโอ QR ตัวจริงเข้ากล้อง ทุกอันเข้าฐานถูกและเข้ากลุ่มถูก ไม่มีข้ามกัน

QR ตัวจริงสำหรับเอาไปปรินต์อยู่ใน `qr code/`

### 🔑 QR ลับสำหรับ admin — `all.png`

สแกนแล้ว **เติมแสตมป์ครบ 19/19 ทันที** (ข้อความในโค้ดคือ `all_qrcode`)
สแกนซ้ำอีกครั้งตอนที่ครบอยู่แล้ว = **ล้างแสตมป์ทั้งหมด** ใช้เป็นปุ่ม reset ได้
เพราะในแอปไม่มีปุ่มล้างแล้ว มีหน่วง 5 วินาทีกันจ่อกล้องค้างแล้วพลิกกลับเอง

> ⚠️ **ข้อความ `all_qrcode` เดาง่ายมาก** QR เก็บแค่ข้อความเปล่าๆ เด็กที่สงสัยว่า
> "ถ้าทำ QR ที่เขียนว่า all_qrcode เองล่ะ" ใช้เว็บสร้าง QR ฟรีก็ได้รางวัลแล้ว
> โดยไม่ต้องเดินสักฐาน ถ้าห่วงเรื่องนี้ให้เปลี่ยนเป็นรหัสเดายาก เช่น
> `all_qrcode_h7q2xk49` แก้ที่ `ADMIN_CODE` ใน [assets/js/app.js](assets/js/app.js)
> กับ `ADMIN_ID` ใน `make_qr_codes.py` ให้ตรงกัน แล้วรัน
> `python make_qr_codes.py --force` เพื่อปรินต์ใหม่
>
> อย่าปรินต์ QR อันนี้แปะไว้ที่ฐานเด็ดขาด เก็บไว้ในมือถือตัวเองพอ

### ถ้าจะเพิ่ม / แก้ฐาน หรือแก้เกณฑ์

แก้ที่หัวไฟล์ [assets/js/app.js](assets/js/app.js) อย่างเดียว

```js
var GROUPS = [
  { key: 'major',      label: 'ฐานกิจกรรมวิชาเอก',            need: 5 },
  { key: 'innovation', label: 'ฐานนวัตกรรมและนิทรรศการแสดงผลงาน', need: 3 }
];
```

ตัวเลข `need`, จำนวนฐาน, ตัวนับ, แถบ progress, ข้อความกติกา และบัตรรับรางวัล
คำนวณจาก 2 ก้อนนี้ทั้งหมด ไม่ต้องไปแก้ HTML/CSS

เพิ่มฐานใหม่แล้วอย่าลืมสร้าง QR:

```bash
python make_qr_codes.py
```

(อันที่มีอยู่แล้วจะข้ามให้ ไม่สร้างซ้ำ)

## 4.5 การตรวจก่อนแจกรางวัล (สำหรับคุณครู)

ในการ์ด **กติกาการรับรางวัล** ถ้านักเรียนผ่านเกณฑ์ทั้งสองกลุ่ม จะมี "บัตรรับรางวัล"
สีเขียวโผล่ขึ้นมา ให้ยื่นหน้าจอให้คุณครูดู บนบัตรมี:

- **จำนวนแสตมป์แต่ละกลุ่ม** พร้อมเกณฑ์ที่ต้องได้ และเครื่องหมายถูก
- **ช่วงเวลาที่สแกน** (สแกนอันแรกถึงอันล่าสุด)
- **กดดูรายการฐานที่สแกน** เห็นทุกฐานพร้อมเวลาจริง ถ้าสแกนรวดเดียว 8 ฐานใน 5 วินาที
  จะเห็นทันทีจากเวลาที่ติดกันหมด

ถ้าไม่ผ่านเกณฑ์ บัตรจะเป็นสถานะล็อกและบอกว่ายังขาดกลุ่มไหนอีกกี่แสตมป์

> ตรงไปตรงมานะครับ: ตอนนี้ไม่มีระบบล็อกว่า "รับรางวัลไปแล้ว" — ถ้าอยากกันคนมารับซ้ำ
> ต้องใช้วิธีนอกแอป (เช่น ให้ครูขีดชื่อในลิสต์ที่จุดแลก) บอกได้ถ้าอยากให้ใส่กลับเข้าไป

## 4.7 หน้ารายละเอียดกิจกรรม

การ์ด **EVENT** บนหน้าแรก เปิดไปหน้า `#/event` มี:

- **กำหนดการ** พิมพ์เป็นข้อความ (อ่านบนมือถือได้เลย ไม่ต้องซูมโปสเตอร์)
- **วิธีใช้ PASSPORT** 4 ขั้นตอน สำหรับเด็กที่เพิ่งเคยใช้
- **แผนผังงาน** ตำแหน่งฐานทั้งหมด (ฐานวิชาเอก = กล่องสีชมพู) แตะขยายเต็มจอ
- **โปสเตอร์กิจกรรม 3 ใบ** แตะแล้วขยายเต็มจอ

ถ้าจะแก้กำหนดการ แก้ใน `index.html` ที่ `<ol class="timeline">` ได้เลย
ส่วนโปสเตอร์เปลี่ยนได้ที่ `assets/img/poster-*.webp` และแผนผังที่ `assets/img/map-venue.webp`

### ตั้งค่าครั้งแรก (ทำครั้งเดียว)

1. เปิด [supabase-setup.sql](supabase-setup.sql) แก้บล็อกสุดท้าย:
   - `secret` = สิ่งที่พี่จะพิมพ์ในช่องกรอกรหัสเพื่อเข้าโหมดแอดมิน
     **ต้องขึ้นต้นด้วยเลข 5 ตัวแล้วตามด้วยตัวอักษร** เช่น `02977focalorsgoat`
     (ตัวอักษรตัวที่ 6 คือสิ่งที่ทำให้ช่องกรอกยอมให้พิมพ์ยาวเกิน 6 ตัว)
   - `display_id` = เลข 6 หลักที่จะโชว์บนโพสต์ของพี่ เช่น `029778`
2. วางทั้งไฟล์ใน **Supabase → SQL Editor → Run**

### โหมดแอดมิน — ซ่อนสนิท

**ไม่มีปุ่มแอดมินในหน้าเว็บเลย** ไม่มีป้าย ไม่มีคำว่า admin ที่ไหน คนทั่วไปเห็นแค่
กระดานธรรมดาที่ดูเหมือนไม่มีใคร moderate

วิธีเข้า: กด **เปลี่ยนรหัส** แล้วพิมพ์ `secret` ลงในช่องกรอกรหัสประจำตัว
- พิมพ์ตัวเลขล้วน → ช่องตัดให้เหลือ 6 หลักตามปกติ
- พอพิมพ์**ตัวอักษร**เป็นตัวที่ 6 → ช่องปลดล็อก พิมพ์ยาวต่อได้
- กดบันทึก → เข้าโหมดแอดมินเงียบๆ โพสต์ขึ้นชื่อ `display_id` ปกติ

พิมพ์ `secret` เดิมซ้ำอีกครั้ง = ออกจากโหมดแอดมิน

**สตริงลับกับเลข display ไม่อยู่ในโค้ดหน้าเว็บเลยสักตัว** — อยู่ในตาราง Supabase ที่
anon อ่านไม่ได้ หน้าเว็บแค่ส่งสิ่งที่พิมพ์ไปถาม server ว่าใช่ไหม กรอกผิดจะขึ้นข้อความ
เดียวกับกรอกเลขผิดธรรมดา ไม่ใบ้ว่ามีระบบนี้อยู่

> ล้าง browser data หรือเปลี่ยนเครื่อง = สิทธิ์หาย พิมพ์ `secret` ใหม่ได้เลย

### สิ่งที่กันไว้แล้ว

- **XSS** — ข้อความทุกอันแสดงผ่าน `textContent` ไม่ใช่ `innerHTML` ใครพิมพ์ `<script>` มาก็เห็นเป็นตัวอักษร
- **เดารหัสแอดมิน** — ตรวจฝั่ง server เท่านั้น กรอกผิดได้ข้อความเดียวกับกรอกเลขผิด
- **สแปม** — 1 รหัสประจำตัว โพสต์ได้ไม่เกิน 5 ครั้ง/นาที (บังคับที่ database)
- **ปลอมเป็นโพสต์ปักหมุด** — RLS บังคับให้โพสต์ใหม่ `pinned = false` เสมอ
- **ยาวเกิน / ว่างเปล่า** — จำกัด 1–500 ตัวอักษรที่ database
- **รหัสไม่ใช่ 6 หลัก** — บังคับซ้ำที่ database ไม่เชื่อฝั่งหน้าเว็บ

### สิ่งที่ยังไม่ได้กัน — ต้องคอยดูเอง

**ไม่มีระบบกรองก่อนโพสต์** ใครพิมพ์อะไรมาขึ้นทันที ปุ่มลบช่วยได้หลังเกิดเหตุเท่านั้น
วันงานควรเปิดหน้ากระดานคาไว้บนเครื่องที่เป็นแอดมิน

`anon key` ที่อยู่ใน `board.js` **เปิดเผยได้ ไม่ใช่ความลับ** — มันถูกออกแบบมาให้อยู่ในหน้าเว็บ
ความปลอดภัยจริงมาจาก RLS ใน SQL ห้ามเอา `sb_secret_` / `service_role` มาใส่แทนเด็ดขาด

## 5. เรื่องกล้อง

- ใช้ `BarcodeDetector` ของเบราว์เซอร์ถ้ามี (Android Chrome — เร็วและทนแสงน้อยกว่า)
  ถ้าไม่มีก็ใช้ jsQR ที่ฝังมาในโฟลเดอร์ (iOS Safari, Firefox)
- **ซูม** ถ้ากล้องรองรับซูมจริง (มือถือส่วนใหญ่รองรับ) สไลเดอร์จะไปคุมเลนส์โดยตรง
  ถ้าไม่รองรับจะ crop ภาพให้แทน ช่วยเรื่องเล็งเป็นหลัก
- ถ้าเคยกดอนุญาตกล้องไปแล้ว รอบต่อไปเข้าหน้าสแกนกล้องจะเปิดเองเลย ไม่ต้องกดซ้ำ
- ออกจากหน้าสแกนหรือสลับไปแอปอื่น กล้องจะปิดให้อัตโนมัติ (ไม่กินแบต ไม่ร้อน)
- มีไฟฉายให้กดถ้าเครื่องรองรับ เผื่อฐานอยู่ในที่มืด

### ปรินต์ QR ให้ใหญ่พอ

จากที่ทดสอบ ตัวสแกนอ่านได้เมื่อ QR กินพื้นที่ **ประมาณ 8% ของความกว้างภาพขึ้นไป**
แปลว่าถ้าปรินต์ QR ขนาด A5 (~15 ซม.) เด็กยืนห่างได้สบายๆ ถ้าปรินต์เล็กกว่า A6
ควรบอกให้เด็กเข้าไปใกล้ๆ หรือใช้ซูมช่วย

## 6. โครงสร้างไฟล์

```
index.html              ทั้งแอปอยู่ในไฟล์เดียว 5 หน้า (landing / scan / progress / reward / event)
assets/css/app.css      design system + ทุกหน้า
assets/css/fonts.css    @font-face ชี้ไปที่ฟอนต์ในเครื่อง
assets/js/app.js        ฐาน+กลุ่ม+เกณฑ์, storage, router, scanner, บัตรรับรางวัล  ← แก้ที่นี่
assets/js/jsqr.js       jsQR 1.4.0 (vendored)
assets/fonts/           Osiris (หัวเรื่องอังกฤษ), Archivo (ละติน), Prompt (ไทย)
assets/img/             ภาพพื้นหลัง + ภาพการ์ด 4 ใบ + โปสเตอร์กิจกรรม 3 ใบ (.webp)
.nojekyll               บอก GitHub Pages ว่าอย่าเอา Jekyll มายุ่ง
context.md              บันทึกการตัดสินใจ/สเปกของงานนี้
serve.py                เซิร์ฟเวอร์ไว้เทสในเครื่อง (ไม่เกี่ยวกับตอน deploy)
assets/js/board.js      กระดานบอกเล่าความรู้สึก (คุย Supabase ผ่าน REST ไม่ใช้ SDK)
supabase-setup.sql      schema + RLS + ฟังก์ชันแอดมิน — วางใน Supabase ครั้งเดียว
build_standalone.py     สร้างเวอร์ชันไฟล์เดียวไว้ที่ standalone/index.html
make_qr_codes.py        สร้าง QR ของทุกฐานลง qr code/ (ข้ามอันที่มีแล้ว)
stamp_assets.py         ใส่ ?v=<hash> ให้ไฟล์ css/js กัน browser ใช้ของเก่าค้าง
image/, qr code/        ไฟล์ต้นฉบับที่พี่ให้มา
```

ฟอนต์ทั้งหมดฝังมาในโฟลเดอร์ ไม่ได้ดึงจาก Google Fonts ตอนรัน — หน้าเว็บเลยไม่วูบ
ถ้า wifi งานช้า และไม่มี request ออกนอกเครื่องเลยสักอัน

**เรื่องฟอนต์**: Archivo กับ Public Sans เป็นฟอนต์ละตินล้วน ไม่มีตัวอักษรไทย
เลยใช้ Archivo คุมภาษาอังกฤษ แล้วให้ตัวไทยตกไปที่ Prompt (ตั้งเป็น
font stack `Archivo, "Prompt"` เบราว์เซอร์จะเลือกให้เองตามตัวอักษร)
ส่วนหัวเรื่อง PASSPORT ยังเป็น Osiris เหมือนเดิม

ภาพในเว็บแปลงเป็น `.webp` แล้ว (5.9 MB → 212 KB) เพื่อให้เด็กที่เล่นผ่านเน็ตมือถือ
โหลดครั้งแรกไว ไฟล์ PNG ต้นฉบับที่พี่ให้มายังอยู่ครบใน `image/` ไม่ได้แตะ
